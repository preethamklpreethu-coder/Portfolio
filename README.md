# Preetham K L — Founder Portfolio

Premium personal portfolio website for **Preetham K L**, Founder & CEO of **Orviqon**.

## Features

- Luxury dark theme with electric teal accents
- AI-inspired animated particle background
- Smooth scroll reveal animations
- Fully responsive (desktop, tablet, mobile)
- SEO-optimized meta tags
- Fast-loading static site (no build step required)

## Quick Start

Open `index.html` in a browser, or serve locally:

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8080`

## Customization

- **Portrait**: Replace the placeholder in the hero section by adding your photo to `assets/` and updating the `.portrait-inner` block in `index.html`
- **Company website**: Update the Orviqon link in the social section if the URL differs from `https://orviqon.com`

## Structure

```
preetham-portfolio/
├── index.html      # Main page
├── css/style.css   # Styles
├── js/main.js      # Animations & interactions
└── assets/         # Images & media
```
